# Wayzyy AI Trip Concierge — Antigravity Build Package

This package contains the project specification and master build prompt for the Wayzyy PS2 AI Trip Concierge hackathon MVP.

## Files

- `00_MASTER_PROMPT_FOR_ANTIGRAVITY.md` — paste/provide this to Antigravity first.
- `01_PRD_Wayzyy_AI_Trip_Concierge.md` — product requirements.
- `02_Technical_Architecture_Wayzyy_AI_Trip_Concierge.md` — system architecture and workflows.
- `03_Security_and_Access_Wayzyy_AI_Trip_Concierge.md` — security, privacy and access rules.
- `04_Frontend_Specification_Wayzyy_AI_Trip_Concierge.md` — booking simulator/frontend requirements.
- `05_Feature_Ticket_List_Wayzyy_AI_Trip_Concierge.md` — implementation tickets and priorities.

## Recommended use

Give Antigravity the complete folder/package and instruct it to read the master prompt and all five supporting documents before implementing.

The intended MVP stack is n8n Cloud + Claude API + Telegram + Google Sheets + OpenWeatherMap + a lightweight HTML/CSS/JS booking simulator.
